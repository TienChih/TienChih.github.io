Objects = sets with a symmetric edge relation (loops allowed, no multi-edges); morphisms = edge-preserving maps. Build a domain G and codomain H, read off HG, and hover a vertex to see the function it represents.

Definitions & what you are looking at
Product (categorical / tensor).   In G × H,   (g,h) ~ (g′,h′)  iff  g ~G g′ and h ~H h′.
Exponential HG.
• Vertices = all functions f : VG → VH (not only the homomorphisms).
• Edges:  f ~ f′  iff  for every edge x ~G y we have f(x) ~H f′(y).
A vertex f carries a loop exactly when f(x) ~H f(y) for all edges x ~G y — i.e. exactly when f is a graph homomorphism. So the looped vertices of HG are precisely Hom(G,H) (shown by default below).
Universal property.   Hom(K × G, H) ≅ Hom(K, HG), naturally in K.   In particular H1 ≅ H (1 = the single looped point) and H0 ≅ 1.
Hover any vertex of HG: each domain vertex x is colored and an arrow is drawn to its image f(x) in H. Click two vertices to trace the paths between them. Node fill color = connected component; a small arc = loop = homomorphism.
